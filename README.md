# OS_2

OS_2 — лабораторная работа по операционным системам: изучение базовых системных вызовов и работы с файлами на языке C.

Состав репозитория
- `lab2.c` — исходный код лабораторной работы  
- `makefile` — автоматизация сборки  
- `doc/` — отчёт, пояснения и дополнительные материалы  
- `.gitignore` — игнорируемые файлы для git

Как использовать
1. Откройте терминал в папке OS_2.
2. Выполните команду:
   ```
   make
   ```
3. Запустите полученный исполняемый файл для проверки работы программы.

Цели лабораторной работы
- Освоить работу с системными вызовами в C.
- Научиться выполнять операции с файлами на уровне ОС.
- Проанализировать поведение программы при различных сценариях работы с файлами.
